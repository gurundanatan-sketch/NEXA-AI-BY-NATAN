# NEXA AI BY NATAN — Server

Server pribadi untuk aplikasi NEXA. Isinya kunci API (Gemini, ElevenLabs, Fish Audio), akun, Premium, dan saran pengguna.
Repo ini **tidak berisi kunci apa pun**. Kunci diisi sendiri saat menekan tombol di bawah.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/gurundanatan-sketch/nexa-server)

1. Tekan tombol di atas, lalu login ke Cloudflare dan GitHub.
2. Isi GEMINI_KEY, ELEVEN_KEY, FISH_KEY, dan OWNER_PASSWORD.
3. Tekan **Deploy**. Database dibuat otomatis. Salin alamat `https://nexa-server.….workers.dev`.
